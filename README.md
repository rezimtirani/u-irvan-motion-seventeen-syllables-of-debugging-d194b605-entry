> Cursor blinks at three
> on the line that worked last night

## Run it

```sh
python3 main.py
```

The program writes the haiku to `/output/entry.txt` (UTF-8, 81 characters, three lines) and checks the gate (1–200 characters) and the 5-7-5 shape before writing.
